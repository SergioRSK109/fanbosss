# Credits

## Countries States Cities Database

The province/region dropdown on the signup form (`src/lib/data/states.json`)
is derived from the [Countries States Cities Database](https://github.com/dr5hn/countries-states-cities-database)
project, licensed under the [Open Database License (ODbL) v1.0](https://opendatacommons.org/licenses/odbl/1-0/).

Only the states/provinces for countries already listed in `src/lib/countries.ts`
were kept; the rest of the upstream dataset (cities, postcodes, and every
other country) was not included.
